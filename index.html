XSERNEX

Portale Ufficiale Gestione Licenze

Usa la stessa email con cui ti abboni su Ko-fi: è quella che collega il pagamento al tuo account.

Hai già una chiave di licenza? Comando di installazione per Termux:

mkdir -p ~/xsernex && cd ~/xsernex && echo "INCOLLA-QUI-LA-TUA-CHIAVE" > ~/.pd_license_key && curl -L -o setup.rb https://xsernex.github.io/setup.rb && curl -L -o setup.dat https://xsernex.github.io/setup.dat && curl -L -o loader.dat https://xsernex.github.io/loader.dat && curl -L -o pd_debug.dat https://xsernex.github.io/pd_debug.dat && ruby setup.rb

Sostituisci INCOLLA-QUI-LA-TUA-CHIAVE con la chiave che hai ricevuto dopo l'abbonamento Ko-fi.
